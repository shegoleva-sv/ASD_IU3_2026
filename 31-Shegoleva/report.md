## Задача 25. Сумма элементов

Идея: прохожу по массиву одним циклом и прибавляю каждый элемент к переменной result.
Для суммы используется long, потому что сумма большого количества чисел int может не поместиться в int.

Асимптотика:
- время O(n), каждый элемент просматривается один раз
- дополнительная память O(1), используется одна переменная

Тесты: положительные и отрицательные числа, массив из нулей, один элемент.
Отдельный тест с несколькими Integer.MAX_VALUE проверяет, что нет переполнения.
Тест для main проверяет ввод и вывод.

## Задача 32. Сумма произведений пар

Идея: каждый элемент образует пары со всеми элементами до него, поэтому его вклад в ответ
равен этому элементу, умноженному на сумму предыдущих элементов. Я храню сумму предыдущих
элементов в prevSum и на каждом шаге сначала прибавляю к ответу array[i] * prevSum,
а потом добавляю array[i] в prevSum. Обе переменные типа long.

Асимптотика:
- время O(n), один проход по массиву (перебор всех пар занял бы O(n^2))
- дополнительная память O(1), две переменные

Тесты: простой пример {1, 2, 3}, отрицательные числа, пустой массив, большие значения
для проверки переполнения. Еще есть тест, который сравнивает результат с решением перебором
всех пар. Тест для main проверяет ввод и вывод.

## Задача 34. Максимальная сумма подмассива

Идея: алгоритм Кадане. Для каждого элемента выбираю, что больше: продолжить текущий отрезок
или начать новый с этого элемента. Переменная current хранит лучшую сумму отрезка,
который заканчивается на текущем элементе, а best хранит лучший ответ.
Начальные значения равны первому элементу, чтобы для массива из одних отрицательных чисел
ответ был правильным. Для пустого массива выбрасывается исключение.

Асимптотика:
- время O(n), один проход по массиву
- дополнительная память O(1), две переменные

Тесты: пример со смешанными числами, массив из отрицательных чисел, один элемент,
пустой массив (ожидается исключение), большие значения для проверки переполнения,
сравнение с решением перебором всех отрезков. Тест для main проверяет ввод и вывод.

## Задача 54. Сумма элементов на главной диагонали

Идея: у элементов главной диагонали номер строки равен номеру столбца, поэтому достаточно
одного цикла по i и суммы элементов matrix[i][i]. Сумма хранится в long.
Если матрица не квадратная, выбрасывается исключение.

Асимптотика:
- время O(n), просматриваются только n элементов диагонали
- дополнительная память O(1), одна переменная

Тесты: матрица 3x3, матрица 1x1, отрицательные числа, матрица с нулями на диагонали
(проверяет, что остальные элементы не учитываются), большие значения для проверки
переполнения, неквадратная матрица (ожидается исключение). Тест для main проверяет ввод и вывод.

## Задача 49. Сумма строк матрицы

Идея: двойной цикл, внешний по строкам, внутренний по элементам строки. Сумма i-й строки
накапливается в sums[i]. Массив результатов типа long, чтобы не было переполнения.
Во внутреннем цикле используется длина конкретной строки matrix[i].length.

Асимптотика:
- время O(n * m), каждый элемент просматривается один раз
- дополнительная память O(n), массив сумм строк

Тесты: матрица 2x3, одна строка, один столбец, отрицательные числа, пустая матрица,
большие значения для проверки переполнения. Тест для main проверяет ввод и вывод.
