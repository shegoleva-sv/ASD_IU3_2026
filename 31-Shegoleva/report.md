## Задача 25. Сумма элементов

**Идея.** Один проход по массиву: каждый элемент прибавляется к накопителю.
Накопитель имеет тип `long`, так как сумма до 10^5 чисел типа `int` может не поместиться в `int`.

**Асимптотика.**
- Время: O(n) — каждый элемент просматривается один раз.
- Память: O(1) дополнительной — одна переменная-накопитель.

**Тесты.** Положительные и отрицательные числа, нули, один элемент — базовые и граничные случаи.
Несколько `Integer.MAX_VALUE` — проверка отсутствия переполнения. Тест `main` — проверка ввода-вывода.

## Задача 32. Сумма произведений пар

**Идея.** Каждый элемент образует пары со всеми предыдущими, поэтому его вклад равен
произведению элемента на сумму предыдущих элементов. За один проход поддерживается эта сумма
и накапливается ответ; оба значения имеют тип `long`.

**Асимптотика.**
- Время: O(n) — один проход вместо перебора всех пар за O(n^2).
- Память: O(1) дополнительной — две переменные.

**Тесты.** Простой пример и отрицательные числа — корректность. Пустой массив — граничный случай.
Большие значения — отсутствие переполнения. Сверка с перебором всех пар — проверка
на произвольных данных. Тест `main` — проверка ввода-вывода.
